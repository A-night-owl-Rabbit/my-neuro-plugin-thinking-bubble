# my-neuro-plugin-thinking-bubble · 思考气泡插件

> [my-neuro(肥牛)](https://github.com/morettt/my-neuro) 内置插件发布仓库 · 无外部依赖、无 API Key
> 当前版本：1.2.0

你说话之后、肥牛开口回答之前，中间总有几秒钟 AI 在"想"。这个插件会在 Live2D 模型头顶冒出一个**萌系"正在思考"气泡**（内置约 50 条随机短句轮播，如「嗯……」「在想喵~」），等 AI 真的开始说话就自动收起——让等待不冷场，还知道它没死机。

## 这是什么？（给完全没接触过的小白）

- **插件**：给肥牛加功能的"扩展包"，放进插件文件夹、重启一次就生效
- 这是一个纯展示型插件：**不需要 API Key、不需要配置服务**，装上重启就能看到效果
- 效果：你发消息 → 稍等半秒 → 模型头顶冒出小气泡 → 文案每隔 2.5 秒换一条 → AI 开始回复（TTS 开口）时气泡消失

## 功能特性

- **出现时机**：语音识别 / 文本发送后、即将请求 LLM 时（`onUserInput` + 短延迟），默认延迟 300ms 防止一闪而过
- **消失时机**：LLM 返回并进入 TTS 前（多事件兜底），不会打断工具调用与语音播放
- **约 50 条萌系文案**：显示期间随机轮换；可在配置里换成你自己的文案列表
- **智能让路**：与歌词气泡同时存在时自动错开，避免重叠
- **位置与大小的可视化调整**：气泡位置和缩放由 WebUI「Live2D设置」的气泡编辑器接管，所见即所得

## 环境要求

- my-neuro（live-2d 桌宠）近期版本；无需任何外部依赖与 API Key

## 安装教程

**方式一（推荐）：WebUI 插件广场一键安装**

1. 打开 my-neuro 的 WebUI 控制面板 → 「广场」→ 插件广场
2. 找到本插件，点击安装（已装过则点更新）
3. 重启 Live2D 桌宠

**方式二：手动安装**

1. 点击本页绿色 `Code` 按钮 → `Download ZIP` 下载并解压
2. 把解压出的文件夹放入（确保 `index.js` 直接位于该目录下，不要多套一层）：

   `my-neuro/live-2d/plugins/community/thinking-bubble/`

3. 重启桌宠应用（老版本手动装的话，也可在 `live-2d/plugins/enabled_plugins.json` 中加一行 `"community/thinking-bubble"`）

> 插件内 `require` 路径相对于插件目录，需与官方插件目录结构一致，不能脱离主项目单独使用。

## 配置教程（逐项讲解）

在 WebUI 插件配置界面（或编辑 `plugin_config.json`）可调整：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 水平偏移 / 垂直偏移 / 气泡缩放 | — | **这三项已由气泡编辑器接管，直接改配置文件无效**。请到 WebUI「Live2D设置」→ 点「调整气泡位置」可视化拖拽调整 |
| 显示延迟（`show_delay_ms`） | 300 | 发出消息后延迟多少毫秒再冒气泡，太大显得迟钝，太小容易一闪而过 |
| 文案切换间隔（`text_change_interval_ms`） | 2500 | 气泡里的文案每隔多少毫秒换一条 |
| 自定义文案（`custom_texts`） | 空 | 想让气泡随机显示的话，填 JSON 数组字符串，例如 `["正在想~","稍等喵","让我康康"]`；留空用内置默认文案 |

## 使用教程（装完怎么看效果 / 怎么玩）

本插件是自动展示型，无需指令触发：

1. 对肥牛随便说句话（比如「今天天气怎么样」）
2. 观察模型头顶是否冒出「正在思考」气泡
3. 等 AI 开始语音回答，气泡应自动消失
4. 想换文案：在配置「自定义文案」里填你喜欢的句子列表；想调位置大小：WebUI「Live2D设置」→「调整气泡位置」

## 常见问题（FAQ）

- **装了没看到气泡？** 确认插件已启用并重启过桌宠；AI 回答太快时气泡可能一闪而过（可把显示延迟调小试试）；确认没有把显示延迟设成超大数值。
- **气泡位置不对/压住模型了？** 不要手改 `offset_x/offset_y`——已被气泡编辑器接管，去 WebUI「Live2D设置」点「调整气泡位置」拖拽调整。
- **气泡太大/太小？** 同样在气泡编辑器里调缩放，不要改 `plugin_config.json`。
- **歌词气泡和思考气泡打架？** 不会，本插件会检测歌词气泡可见性并自动让路。
- **怎么换回默认文案？** 把「自定义文案」清空保存即可。

## 故障排查

1. 日志搜 `thinking-bubble`，可看到气泡注入与显隐事件
2. 完全不出现且日志无记录：确认插件目录层级正确（`index.js` 直接在插件文件夹下）、主程序版本支持该插件
3. 还有问题请到 [本仓库 Issues](https://github.com/A-night-owl-Rabbit/my-neuro-plugin-thinking-bubble/issues) 提问

## 更新与卸载

- **更新**：插件广场点更新，或手动覆盖插件文件夹后重启
- **卸载**：WebUI「插件管理」停用并删除 `live-2d/plugins/community/thinking-bubble/` 文件夹即可

## 技术说明（进阶）

- 依赖 my-neuro 插件基类与事件总线（`plugin-base.js`、`event-bus.js`、`events.js`）
- 不监听 `TTS_INTERRUPTED` 作为隐藏条件，避免新对话打断旧 TTS 时误清「待显示」定时器
- 歌词气泡可见性通过 `getComputedStyle` 判断，避免与仅写在 CSS 里的 `display:none` 误判冲突
- 气泡缩放通过 CSS `transform: scale()` 实现，`transformOrigin` 设为 `bottom left`，缩放后仍锚定在模型附近
